# Rafia.dev — Portfolio

Portfolio personnel de **Rafiatou Soumaila Hamidou**, Développeuse Front-End basée à Niamey, Niger.

##  Aperçu

Ce site vitrine présente mon parcours, mes compétences, mes projets récents et mes services en tant que développeuse front-end. Il est entièrement responsive et conçu avec HTML, CSS et Bootstrap.

##  Technologies utilisées

- **HTML5** — Structuration sémantique et accessible du contenu
- **CSS3** — Mise en forme, animations et design responsive
- **Bootstrap 5** — Grille responsive et composants UI
- **Bootstrap Icons** — Icônes vectorielles

##  Palette de couleurs

Le site utilise des variables CSS centralisées pour une personnalisation facile :

```css
--couleur-principale: #3EB3BD;
--couleur-secondaire: #48D5DA;
--couleur-degrade: linear-gradient(135deg, #3EB3BD, #48D5DA);
```

##  Responsive Design

Le site s'adapte à toutes les tailles d'écran grâce à la grille Bootstrap et des media queries personnalisées :
-  Mobile (< 768px)
-  Tablette (768px – 992px)
-  Desktop (> 992px)
